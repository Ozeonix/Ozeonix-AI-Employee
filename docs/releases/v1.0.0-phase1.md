# Release Notes - v1.0.0 (Phase 1 Initial Release)

**Release Date**: August 5, 2026

## Overview
Initial enterprise release of Phase 1 Core Platform for **Ozeonix AI Employee**.

### Key Deliverables
- **Core Platform**: Multi-tenant Company, Domain, and Subscription management.
- **Authentication**: JWT access & refresh token lifecycle, password hashing, API Key authentication.
- **RBAC**: Super Admin role, granular permissions, role assignment.
- **Database**: PostgreSQL 16 + Prisma ORM + automatic audit triggers + soft delete + version control.
- **Infrastructure**: Containerized with Docker Compose (PostgreSQL 16 with `pgvector`, Redis 7, App).
